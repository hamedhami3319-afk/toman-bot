# 🤖 ربات تلگرام معاملات تومان و صرافی (مخصوص صرافان)

این پروژه نسخه کامل و بهینه‌سازی‌شده برنامه صرافی برای ربات تلگرام است که به صورت **۱۰۰٪ مستقل و خودکفا (Self-Contained)** طراحی شده است. تمام فونت‌ها و منابع مستقیماً در کدهای جاوااسکریپت تعبیه شده‌اند و هیچ نیازی به آپلود فایل‌های مجزا نیست.

---

### ✨ قابلیت‌ها و ویژگی‌های کلیدی:

1. **ثبت فوق‌هوشمند معاملات (صوتی و متنی):**
   - پشتیبانی از تمام الگوهای گفتاری صرافان:
     - `۲۰۰۰م خرید از احمد نرخ ۲۵۶۰۰۰ در لیست حامد`
     - `۲ میلیارد خرید از احمد نرخ ۲۵۶۰۰۰`
     - `دو میلیارد خرید از وحید الله فی ۲۵۶۰۰۰`
     - `یه نرخ ۲۵۶۰۰۰ خرید از وحید الله در لیست حامد`
   - تشخیص پسوندهای عددی: «م / میلیون»، «هزار / k»، «میلیارد / b»، «همت» و کلمات حروفی اعداد
   - **انتخاب هوشمند لیست مقصد:** اگر نام لیست در متن گفته شود (مثلاً `در لیست حامد`) مستقیماً در همان لیست ثبت می‌گردد. در غیر این صورت، دکمه‌های شیشه‌ای لیست‌ها نمایش داده می‌شود تا با ۱ لمس لیست مقصد انتخاب شود.
   - **پشتیبانی از پیام صوتی (ویس 🎙️):** با ارسال ویس، گفتار شما تبدیل به متن شده و معامله به طور خودکار ثبت می‌گردد (با تنظیم کلید رایگان `GEMINI_API_KEY`).

2. **خروجی تصویر با وضوح بسیار بالا (2X Retina) و کات دقیق:**
   - استفاده از فونت رسمی **وزیرمتن (Vazirmatn)** تعبیه‌شده در کد (بدون نیاز به آپلود فایل فونت مجزا)
   - رندر با مقیاس دوبرابری رتینا برای کیفیت و خوانایی حداکثری در گوشی‌های موبایل
   - **برش طبیعی (Natural Height Crop):** در صورت کم بودن تعداد معاملات، عکس دقیقاً بعد از فاکتور و بدون هیچ حاشیه سفید خالی اضافه برش می‌خورد.

3. **خروجی PDF رسمی A4:**
   - تولید سند تمیز و باکیفیت استاندارد برای اشتراک‌گذاری یا چاپ A4.

4. **خروجی متنی رسمی و ارسال به واتساپ:**
   - قالب متنی کاملاً هماهنگ با نسخه اندروید (شامل تاریخ، روز، جدول خریدات، فروشات، میانگین موزون و سود/ضرر)
   - دکمه ارسال مستقیم و اشتراک متن در واتساپ (`api.whatsapp.com`)

5. **جستجوی پیشرفته (Search):**
   - جستجوی سریع در تمام لیست‌ها بر اساس نام مشتری، نرخ، مبلغ و کد لیست با نرمال‌سازی کامل کاراکترهای فارسی/عربی.

6. **ویرایش و حذف:**
   - دکمه‌های شیشه‌ای زیر هر معامله برای ویرایش فیلدها یا حذف سریع
   - فرم تعاملی برای ویرایش نام مشتری، مبلغ تومان، نرخ یا تغییر جهت (خرید/فروش).

## 🚀 راهنمای سریع راه‌اندازی و آپلود روی GitHub و Render

### ۱. دریافت توکن ربات از BotFather
- در تلگرام به [@BotFather](https://t.me/BotFather) رفته و با دستور `/newbot` ربات خود را ساخته و **HTTP API Token** را کپی کنید.

### ۲. آپلود فایل‌ها در GitHub
فایل‌های این پوشه کاملاً مستقل و سبک هستند:
- `bot.js`
- `renderer.js`
- `embeddedFonts.js`
- `package.json`
- `render.yaml`
- `.gitignore`
- `.env.example`

کافیست این فایل‌ها را در مخزن گیت‌هاب خود بارگذاری فرمایید.

### ۳. استقرار رایگان در Render.com
1. در [Render.com](https://render.com) وارد شده و روی **New +** > **Web Service** کلیک کنید.
2. مخزن گیت‌هاب را انتخاب کرده و تنظیمات زیر را وارد نمایید:
   - **Build Command:** `npm install`
   - **Start Command:** `node bot.js`
   - **Instance Type:** `Free`
3. در بخش **Environment Variables**:
   - `BOT_TOKEN`: توکن تلگرام دریافتی از BotFather
   - `GEMINI_API_KEY` (اختیاری برای فعال‌سازی پردازش ویس صوتی صرافان): کلید هوش مصنوعی جمینای
4. دکمه **Deploy Web Service** را بزنید. ربات ظرف ۱ الی ۲ دقیقه آنلاین شده و به صورت ۲۴ ساعته فعال خواهد بود! 🎉
