# 🤖 ربات تلگرام معاملات تومان و صرافی (مخصوص صرافان)

این پروژه تبدیل‌شده نرم‌افزار صرافی اندروید به یک ربات تلگرام پرسرعت، سبک و دقیق است که تمامی ویژگی‌های نسخه اصلی را پوشش می‌دهد:

### ✨ قابلیت‌های اصلی ربات:
1. **ثبت هوشمند معاملات با دستیار صوتی و متنی:**
   - تشخیص جملات صرافی مانند `خرید احمد ۲ م ۲۵۶۰۰۰۰` یا `فروش رضا ۵۰۰ هزار ۲۵۵۰۰`
   - پشتیبانی از پسوندهای «م / میلیون»، «هزار / k»، «میلیارد / b»، شهرها و ولایات
   - **انتخاب هوشمند لیست مقصد:** اگر نام لیست در جمله ذکر شده باشد (مثلاً `در لیست حامد`) مستقیماً در آن لیست ثبت می‌شود؛ اگر ذکر نشود، دکمه‌های شیشه‌ای لیست‌ها نمایش داده شده تا با یک کلیک لیست دلخواه را انتخاب کنید!
2. **خروجی تصویر با کات دقیق (Natural Crop):**
   - طراحی مطابق سند استاندارد صرافی و فونت رسمی **وزیرمتن (Vazirmatn)**
   - کات خودکار بدون فضای سفید اضافی (اگر معاملات کم باشد، تصویر به اندازه دقیق جداول بریده می‌شود)
3. **خروجی PDF استاندارد A4:**
   - تولید مستقیم فایل PDF رسمی با کیفیت بالا جهت پرینت
4. **خروجی متنی رسمی و ارسال به واتساپ:**
   - خروجی متنی دقیقاً مطابق با نسخه اندروید (شامل تاریخ، روز هفته، خطوط جداکننده، میانگین خرید و فروش و سود/ضرر)
   - دکمه اشتراک‌گذاری مستقیم در واتساپ (`api.whatsapp.com`)
5. **جستجوی پیشرفته (Search):**
   - جستجو بر اساس نام طرف معامله، مبالغ، نرخ‌ها و کد لیست‌ها با نرمال‌سازی حروف فارسی/عربی
6. **ویرایش و حذف سریع:**
   - دکمه‌های ویرایش و حذف زیر هر معامله
   - فرم تعاملی ویرایش نام، مبلغ، نرخ یا تغییر جهت (خرید/فروش)
   - پشتیبانی از دستورات متنی `حذف ردیف ۱` یا `ویرایش ردیف ۱`

## 🚀 راهنمای راه‌اندازی و آپلود روی GitHub و Render

### مرحله اول: دریافت توکن ربات از تلگرام
1. در تلگرام به ربات **[@BotFather](https://t.me/BotFather)** پیام دهید.
2. دستور `/newbot` را ارسال کرده و نام و نام‌کاربری (username) برای ربات خود تعیین کنید.
3. در پایان، یک **HTTP API Token** دریافت می‌کنید (مثلاً `7123456789:AAH...`).

### مرحله دوم: آپلود روی GitHub
1. در سایت [GitHub.com](https://github.com) یک مخزن (Repository) جدید به صورت **Public** یا **Private** بسازید.
2. فایل‌های این پوشه را در مخزن خود آپلود یا push کنید:
   - `bot.js`
   - `renderer.js`
   - `package.json`
   - `render.yaml`
   - `fonts/` (پوشه حاوی فونت‌های وزیرمتن)
   - `.gitignore`

### مرحله سوم: استقرار رایگان در Render.com
1. وارد سایت [Render.com](https://render.com) شوید (با حساب گیت‌هاب لاگین کنید).
2. دکمه **New +** را زده و **Web Service** را انتخاب کنید.
3. مخزن گیت‌هاب خود را انتخاب کنید.
4. تنظیمات:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node bot.js`
   - **Instance Type:** `Free`
5. در بخش **Environment Variables**:
   - کلید: `BOT_TOKEN`
   - مقدار: توکن ربات تلگرام دریافتی از BotFather
6. روی **Deploy Web Service** کلیک کنید.
7. ربات شما ظرف ۲ دقیقه آنلاین شده و آماده استفاده دائمی ۲۴ ساعته خواهد بود! 🎉
